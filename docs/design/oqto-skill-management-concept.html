# Frontend Design

Build intentional interfaces that avoid generic
AI aesthetics and respect the existing product.

## Workflow

1. Understand the user's goal
2. Choose a clear visual direction
3. Implement and verify responsively
User-level surface

My Skills Library

Manage global skills in ~/.agents/skills/, browse trusted stores, inspect updates, and explicitly opt into third-party installation.

01Installed

Edit global skills, inspect origins, view usage across workspaces, or remove safely.

02Trusted stores

Browse administrator-approved multi-skill repositories and pinned versions.

03Custom source

Opt in, review files and scripts, then install from Git or the npm installer.

04Updates

Show available updates. Never merge or update silently in v1.

Administrator surface

Skill Policies & Stores

Declare Oqto-shipped skill identity and policy instead of guessing from filesystem paths.

POLICY ARequired + immutable

Always active, visible, not editable. Administrator may override distribution defaults.

POLICY BOptional + immutable

User can activate per workspace but cannot modify the shipped source.

POLICY CEditable starter

Installed as user-owned content and may diverge from the distribution.

TRUSTApproved stores

Configure one or more Git catalogs, credentials, branches, and review policy.

Recommended boundary: the catalog owns discovery, activation, provenance, policy, conflicts, and updates. The existing file tree/editor owns content editing. Catalog refresh can be live even if Pi only reloads its prompt-time skill registry when a new session starts.
